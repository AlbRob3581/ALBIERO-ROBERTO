*Questa pagina Web serve per configurare/creare un file .bat e uno .txt. Il file .bat vi servira' per configurare la connessione ethernet per comunicare con la rete desiderata. Pulsante "scegli file": puoi richiamare un file txt generato precedentemente dal sito per richiamare le impostazioni di connessione e modificare il file per ricreare il file .bat .

*"Copia comando WMIC": e' un pulsante che copia negli appunti un comando da incollare nel prompt dei comandi per eseguire la visulazzazione dei nomi delle connessioni.

*"Copia comando controllo connessioni": e' un pulsante che copia negli appunti un comando da incollare nel prompt dei comandi per eseguire l'apertura della finestra di windows per la visualizzazione del nome della porta di rete.

*"Nome della porta ethernet": e' un campo di testo dove si dovra' scrivere il nome della porta ethernet ricavato dagli altri 2 pulsanti sopra descritti.

*"Nome Connessione:" e' un campo di testo dove dovrai scrivere la descrizione a cui fara' riferimenti i parametri di connessione

*"Indirizzo IP:" e' un campo di testo per l'inserimento dell'indirizzo IP ad es. 192.168.1.1

*"Subnet Mask:" e' un campo di testo per l'inserimento dell'indirizzo della subnet mask ad es. 255.255.255.255

*"DNS:" e' un campo di testo per l'inserimento dell'indirizzo DNS se necessario. Ad-Guard ne suggerisce uno gratuito contro la pubblicita': 94.140.14.14
